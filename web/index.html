월별 판매실적 업로드

RFC005(월말마감실적)로 자동 수집되지만, 긴급 보정이 필요한 경우 특정 월의 판매실적을 수동으로 업로드할 수 있습니다.

업로드 설정

마감월을 선택하고 해당 월의 자재별 판매실적 파일을 업로드하세요. 기존 데이터가 있으면 덮어씁니다.

마감월과 파일을 선택하세요.

엑셀 템플릿 안내

  • 필수 컬럼: item_code, sales_actual
  • item_code = 자재코드, sales_actual = 해당 마감월 판매실적 수량
  • 수량은 숫자로 입력하고 비어있는 값은 0으로 처리됩니다.
  • 업로드하면 선택한 마감월의 월별 판매실적 데이터(monthly-sales-records)에 반영됩니다.

* 월 총 CAPA = 시간당 CAPA × 일 가동 시간 × 월 가동 일수

      엑셀/CSV 일괄 업로드

      엑셀 또는 CSV 파일을 업로드하면 여러 자재의 생산계획을 한 번에 등록할 수 있습니다.
      아래 템플릿을 내려받아 작성하거나, 동일한 컬럼명을 사용해 파일을 준비하세요.

      • 필수 컬럼: item_code, item_name, category, production_line, month(YYYY-MM), production_plan, beginning_inventory, target_ending_inventory
      • 판매 계획(sales_plan)과 라인 CAPA는 각각 판매계획 업로드/라인 CAPA 관리 화면에서 자동 반영됩니다.
      • month는 YYYY-MM 형식 또는 Excel 날짜(월 기준)로 입력하세요.
      • 수량 컬럼은 숫자만 입력하며, 공란은 0으로 처리됩니다.

      라인별 시간당 CAPA, 가동 시간, 가동 일수를 기반으로 월 총 CAPA를 일괄 등록합니다.
      업로드한 값은 동일 월·카테고리·라인 조합의 기존 데이터를 최신 값으로 덮어씁니다.

      • 필수 컬럼: line_category, production_line, month(YYYY-MM), daily_capa, daily_operating_hours, planned_operating_days
      • computed_capa 컬럼을 추가하면 그대로 사용하고, 없으면 자동으로 시간당 CAPA × 일 가동 시간 × 월 가동 일수를 계산합니다.
      • 비고는 note 컬럼으로 선택 입력할 수 있으며, 숫자 필드는 모두 0보다 큰 값이어야 합니다.
      • 라인/카테고리 표기는 등록 화면의 자동 완성 값과 동일하게 작성하면 입력 시 도움이 됩니다.

      자재 코드별 라인 매핑과 시간당 생산 수량을 일괄 등록하거나 갱신합니다.
      동일 자재 코드는 업로드된 값으로 덮어쓰여 최신 정보가 반영됩니다.

      • 필수 컬럼: item_code, production_line, hourly_throughput
      • item_code는 자동으로 대문자로 변환되며, 공백 없이 입력하세요.
      • hourly_throughput은 0보다 큰 숫자로 작성해야 하며, 필요 시 소수점 한 자리까지 입력할 수 있습니다.
      • 생산 라인은 등록 화면의 자동 완성 목록과 동일한 라벨을 사용하면 관리가 쉬워집니다.

      자재순서 업로드

      자재별 우선순위를 엑셀로 업로드하면 카테고리 내 정렬 순서가 일괄 적용됩니다.
      아래 템플릿을 내려받아 우선순위 숫자를 입력한 뒤 업로드하세요.

      • 필수 컬럼: item_code (자재 코드), 우선순위
      • 우선순위는 1 이상의 정수로 입력하세요 (숫자가 낮을수록 높은 우선순위).
      • 한 번 설정하면 해당 자재의 모든 월에 동일하게 적용됩니다.
      • 빈 칸으로 두면 기존 우선순위가 초기화(삭제)됩니다.
